# Release Notes - YOUMI Builder RC1

We are proud to announce the **Release Candidate 1 (RC1)** release of **YOUMI Builder**, completing its evolution into an enterprise-grade visual application builder.

YOUMI Builder RC1 represents a professional visual workspace that enables developers, designers, and business agencies to visual-engineer complete, responsive, multi-framework web applications.

---

## 🚀 Architectural & Platform Achievements

### 1. Unified Multi-Workspace Control Pane
- Divided Column 3 into three highly focused tabs:
  1. **Packs Checklist**: Easily manage modular layout parts inclusion.
  2. **Layers Manager**: Drag-less section visual ordering (`Move Up` / `Move Down` controllers) alongside eye visibility toggles.
  3. **Property Inspector**: Modify global styling parameters, currencies, contact telephone directories, store names, and color schemes.

### 2. Live Device-Viewport Simulation
- High-fidelity visual simulated canvas showing updates reactively.
- Quick-toggle layout scopes for **Desktop**, **Tablet**, and **Mobile** viewports.
- Responsive multiscale zooming (50%, 75%, 100%, 125%) to inspect layouts on any screen size.
- **Click-to-Focus Layouts**: Clicking any section inside the live preview simulator automatically triggers the left panel to display that block's dedicated PACK editor.

### 3. Integrated Local Asset Engine
- Interactive HTML5 Drag-and-Drop system to convert local PNG, JPG, JPEG, WEBP, or SVG files to Base64 data strings inside active memory instantly.
- Manual file-selection dialog bridge.
- Full-text dynamic icon search and injection utilizing the entire Lucide Icon Library.

### 4. Advanced Multi-Framework Export
- **React + Vite SPA Export**: Compiles standalone client code bundles equipped with VS Code configurations, responsive grids, Tailwind styling setups, and TypeScript variables.
- **Next.js App Router Export**: Scaffolds full Next.js 15 SSR projects with folder hierarchies, hydration boundaries, client boundary tags (`'use client'`), and theme variables.

### 5. Infinite Progress History
- Multi-state history tracker queue with main header action buttons and integrated keyboard event listeners (`Ctrl+Z` / `Ctrl+Y`) supporting up to 50 active edit rollbacks.

## 🛠️ Security, Performance & Quality Standards

- **Electron Security Rules**: Adheres to strict sandboxing, context isolation, secure IPC communications, and CORS asset policies.
- **Strict Quality Compliance**: Certified with zero TypeScript errors, zero linter warnings, and 100% build verification.
- **Accessible & Multilingual Design**: High-contrast, custom font pairings (such as Cairo, Inter, JetBrains Mono) with native RTL and LTR support.
